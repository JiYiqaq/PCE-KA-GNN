# Data directory

- `raw/Active_Database.csv` is the immutable source dataset bundled under CC BY 4.0. Do not overwrite it with processed data.
- `processed/` is created and populated by the training pipeline. Generated `.pt` and `.pth` caches are intentionally ignored by Git because they can exceed GitHub's normal single-file limit.

See `../DATA_LICENSE.md` for provenance, license and checksum information.
